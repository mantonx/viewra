## When to Archive vs Delete

**Archive** when:
- The doc describes completed work (historical value)
- It might inform future similar work
- It documents decisions or analysis

**Delete** when:
- The doc is purely draft/WIP with no value
- It duplicates content that exists elsewhere
- It contains incorrect/misleading information
