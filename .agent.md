## 🚨 CRITICAL RULES (Read First)

### Rule 1: DRY - Don't Repeat Yourself

**Before writing code, ask:**
1. Does this logic exist elsewhere? → Search `internal/pkg/` first
2. Will 2+ domains use it? → Extract to `internal/pkg/<category>/`
3. Am I copy-pasting? → 🛑 STOP. Extract to function/utility

**Common violations:**
- ❌ Duplicate validation → Extract to `internal/pkg/validator/`
- ❌ Same string logic → Extract to `internal/pkg/stringutil/`
- ❌ Redundant functions → Consolidate

### Rule 2: Layer Boundaries (NEVER VIOLATE)

**Domain** (`internal/domain/`): ✅ Standard lib only | ❌ NO Gin, DB drivers, FFmpeg  
**Infrastructure** (`internal/infrastructure/`): ✅ Implements domain interfaces | ✅ sqlc, FFmpeg allowed  
**Application** (`internal/application/`): ✅ Orchestrates use cases | ❌ NO HTTP or DB  
**Interfaces** (`internal/interfaces/`): ✅ Gin handlers | ✅ Uses application layer

**Dependency flow**: `Interfaces → Application → Domain ← Infrastructure`

### Rule 3: Dual Database Support

ALWAYS support SQLite (default) + PostgreSQL:
- Use `sqlc` with build tags: `//go:build sqlite` / `//go:build postgres`
- Separate query files: `library.sql` (SQLite `?`) vs `library_postgres.sql` (PostgreSQL `$1`)

### Rule 4: Documentation

❌ NEVER create: CHANGES.md, SUMMARY.md, PROGRESS.md, task summaries  
✅ ALWAYS update: `docs/PROJECT_PLAN.md` (mark tasks), code comments, existing docs

## Quick Reference

### File Placement

| What | Where |
|------|-------|
| Entity | `internal/domain/<entity>/entity.go` |
| Repository interface | `internal/domain/<entity>/repository.go` |
| Domain service | `internal/domain/<entity>/service.go` |
| Domain errors | `internal/domain/<entity>/errors.go` |
| Repo implementation | `internal/infrastructure/persistence/<entity>/repository.go` |
| SQL queries | `internal/infrastructure/persistence/<entity>/queries/<table>.sql` |
| Shared utilities | `internal/pkg/<category>/` |
| Use case | `internal/application/<entity>/use_case.go` |
| HTTP handler | `internal/interfaces/http/<entity>/handler.go` |
| Tests | Same package, `*_test.go` suffix |

### Key Patterns

**Repository:**
```go
// 1. Domain interface
type LibraryRepository interface {
    Create(ctx context.Context, lib *Library) error
}

// 2. Infrastructure impl
type repo struct { queries *db.Queries }

// 3. Inject in main.go
repo := persistence.NewLibraryRepository(db)
service := library.NewService(repo)
```

**Errors:**
```go
// Domain errors
var ErrLibraryNotFound = errors.New("library not found")

// Wrap with context
return fmt.Errorf("failed to create: %w", err)
```

**Testing:**
```go
func TestEntity_IsValid(t *testing.T) {
    tests := []struct {
        name string
        entity Entity
        wantErr error
    }{{ name: "valid", entity: Entity{...}, wantErr: nil }}
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            if err := tt.entity.IsValid(); err != tt.wantErr {
                t.Errorf("got %v, want %v", err, tt.wantErr)
            }
        })
    }
}
```

## Domain Layer Rules

**Structure per entity:**
```
internal/domain/<entity>/
├── entity.go      # Business object + validation
├── types.go       # Enums, value objects
├── errors.go      # var Err... = errors.New(...)
├── repository.go  # Interface only
├── service.go     # Complex business logic
└── *_test.go
```

**Allowed imports:** `errors`, `strings`, `time`, `fmt`, `path/filepath` - standard lib only  
**Forbidden:** Gin, database/sql, sqlc, FFmpeg, any external package

---

## Infrastructure Layer

**Structure:**
```
internal/infrastructure/
├── persistence/<entity>/
│   ├── repository.go           # Implements domain interface
│   └── queries/
│       ├── <table>.sql         # SQLite (?)
│       └── <table>_postgres.sql # PostgreSQL ($1)
├── ffmpeg/client.go
└── filesystem/scanner.go
```

**sqlc queries:**
```sql
-- name: CreateLibrary :one
INSERT INTO libraries (name, path) VALUES (?, ?) RETURNING *;

-- name: GetLibraryByID :one
SELECT * FROM libraries WHERE id = ? LIMIT 1;
```

## Development Workflow

**Creating a feature (e.g., Library):**

1. **Domain**: `entity.go`, `repository.go`, `service.go`, `errors.go`, tests
2. **Infrastructure**: Migration, `queries/*.sql`, `repository.go`, `sqlc generate`
3. **Application**: `use_case.go`, `dto.go`
4. **Interfaces**: `handler.go`, update routes in `server.go`
5. **Test & Commit**: `go test ./...`, update `PROJECT_PLAN.md`, `git commit`

## Common Mistakes

❌ `import "database/sql"` in domain  
❌ `import "github.com/gin-gonic/gin"` in domain  
❌ Raw SQL: `db.Query("SELECT ...")`  
❌ Skipping validation before repo.Create()  
❌ Ignoring errors
