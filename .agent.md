## Core Principles

### 1. Architecture Rules (STRICT)

**Domain Layer** (`internal/domain/`):
- ❌ **NEVER** import external packages (no Gin, no database drivers, no FFmpeg)
- ✅ Only standard library imports allowed
- ✅ Define interfaces for repositories
- ✅ Pure business logic only
- ✅ Framework-agnostic code

**Application Layer** (`internal/application/`):
- ✅ Uses domain layer
- ✅ Orchestrates use cases
- ✅ Defines DTOs (Data Transfer Objects)
- ❌ No HTTP or framework code
- ❌ No direct database access

**Infrastructure Layer** (`internal/infrastructure/`):
- ✅ Implements domain interfaces
- ✅ Database access via sqlc
- ✅ FFmpeg integration
- ✅ External dependencies allowed
- ✅ Repository implementations here

**Interfaces Layer** (`internal/interfaces/`):
- ✅ HTTP handlers (Gin)
- ✅ Middleware
- ✅ API endpoints
- ✅ Uses application layer only

### 2. Dependency Flow

```
Interfaces → Application → Domain ← Infrastructure
```

**Rule**: Dependencies point inward toward Domain. Infrastructure implements Domain interfaces.

### 3. Database Support (CRITICAL)

**Dual Database Support Required**:
- ✅ **SQLite** (default): For development and home/personal use
- ✅ **PostgreSQL**: For production and multi-user deployments
- ✅ Write database-agnostic SQL that works on both
- ✅ Test migrations and queries on BOTH databases
- ✅ Document any database-specific behavior

**Testing Requirements**:
```bash
# Test with SQLite (default)
DB_DRIVER=sqlite go test ./...

# Test with PostgreSQL (if available)
DB_DRIVER=postgres DB_HOST=localhost DB_USER=viewra DB_PASSWORD=test go test ./...
```

**SQL Compatibility Guidelines**:
- ✅ Use standard SQL types (TEXT, INTEGER, BOOLEAN)
- ✅ SQLite uses `AUTOINCREMENT`, PostgreSQL uses `SERIAL`
- ✅ SQLite uses `DATETIME`, PostgreSQL uses `TIMESTAMP`
- ✅ SQLite uses `REAL`, PostgreSQL uses `DOUBLE PRECISION`
- ✅ Keep separate migration files: `migrations/` (SQLite) and `migrations/postgres/`
- ❌ Avoid database-specific functions without fallback
- ❌ Don't assume `RETURNING *` works identically

**Migration Strategy**:
- Maintain parallel migrations for SQLite and PostgreSQL
- Test both migration paths in CI/CD
- Document differences in migration comments

### 4. Database Access

**ALWAYS use sqlc**:
- ✅ Write SQL queries in `internal/infrastructure/database/sqlc/queries/`
- ✅ Define schema in `internal/infrastructure/database/sqlc/schema.sql`
- ✅ Run `sqlc generate` to create type-safe Go code
- ❌ **NEVER** write raw SQL in Go code
- ❌ **NEVER** use an ORM (no GORM, no ent)

### 5. Code Generation

**Before writing implementations**:
1. Write SQL queries (sqlc)
2. Generate code: `sqlc generate`
3. Write Swagger comments
4. Generate docs: `swag init -g cmd/server/main.go`
5. Generate frontend client: `npm run generate:api`

```go
package repository

import (
    "context"
    "github.com/yourusername/viewra2/internal/domain/library"

type libraryRepository struct {

        Type: string(lib.Type),
```

### When creating a use case:

```go
// internal/application/library/create_library.go
package library

import (
    "context"
    "github.com/yourusername/viewra2/internal/domain/library"
)

type CreateLibrary struct {
    repo library.Repository
}

func NewCreateLibrary(repo library.Repository) *CreateLibrary {
    return &CreateLibrary{repo: repo}
}

func (uc *CreateLibrary) Execute(ctx context.Context, dto CreateLibraryDTO) error {
    // Validate
    // Create entity
    lib := &library.Library{
        Name: dto.Name,
        Path: dto.Path,
        Type: library.LibraryType(dto.Type),
    }
    // Save
    return uc.repo.Create(ctx, lib)

```

### When creating an HTTP handler:

```go
// internal/interfaces/http/handlers/library/handler.go
package library

import (
    "net/http"
    "github.com/gin-gonic/gin"
    "github.com/yourusername/viewra2/internal/application/library"
)

type Handler struct {
    createLibrary *library.CreateLibrary
}

func NewHandler(createLib *library.CreateLibrary) *Handler {
    return &Handler{createLibrary: createLib}
}

// CreateLibrary godoc
// @Summary Create a new library
// @Description Create a new media library
// @Tags libraries
// @Accept json
// @Produce json
// @Param library body CreateLibraryRequest true "Library details"
// @Success 201 {object} LibraryResponse
// @Failure 400 {object} ErrorResponse
// @Router /api/libraries [post]
func (h *Handler) CreateLibrary(c *gin.Context) {
    var req CreateLibraryRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        c.JSON(http.StatusBadRequest, ErrorResponse{Error: err.Error()})
        return
    }
    
    dto := library.CreateLibraryDTO{
        Name: req.Name,
        Path: req.Path,
        Type: req.Type,
    }
    
    if err := h.createLibrary.Execute(c.Request.Context(), dto); err != nil {
        c.JSON(http.StatusInternalServerError, ErrorResponse{Error: err.Error()})
        return
    }
    
    c.JSON(http.StatusCreated, LibraryResponse{Message: "Library created"})
}
```

## Common Patterns

### Pattern 1: Repository Pattern

```go
// Domain defines interface
type MediaRepository interface {
    Create(ctx context.Context, media *Media) error
    GetByID(ctx context.Context, id int64) (*Media, error)
    List(ctx context.Context, filter ListFilter) ([]*Media, error)
}

// Infrastructure implements
type mediaRepository struct {
    queries *db.Queries
}

func NewMediaRepository(q *db.Queries) domain.MediaRepository {
    return &mediaRepository{queries: q}
}
```

### Pattern 2: Dependency Injection (in main.go)

```go
func main() {
    // Infrastructure
    dbConn := database.Connect(cfg.DatabaseURL)
    queries := db.New(dbConn)
    
    // Repositories
    libraryRepo := repository.NewLibraryRepository(queries)
    mediaRepo := repository.NewMediaRepository(queries)
    
    // Services (if needed)
    mediaService := media.NewService(mediaRepo, ffmpegClient)
    
    // Use Cases
    createLibrary := application.NewCreateLibrary(libraryRepo)
    getMedia := application.NewGetMedia(mediaService)
    
    // Handlers
    libraryHandler := handlers.NewLibraryHandler(createLibrary)
    mediaHandler := handlers.NewMediaHandler(getMedia)
    
    // Router
    router := setupRouter(libraryHandler, mediaHandler)
    router.Run(":3000")
}
```

### Pattern 3: Error Handling

```go
// Domain errors (internal/domain/library/errors.go)
package library

import "errors"

var (
    ErrLibraryNotFound = errors.New("library not found")
    ErrInvalidPath     = errors.New("invalid library path")
    ErrDuplicatePath   = errors.New("library path already exists")
)

// Use in service
func (s *Service) ValidatePath(path string) error {
    if !filepath.IsAbs(path) {
        return ErrInvalidPath
    }
    if _, err := os.Stat(path); os.IsNotExist(err) {
        return ErrInvalidPath
    }
    return nil
}

// Handle in handler
func (h *Handler) CreateLibrary(c *gin.Context) {
    if err := h.createLibrary.Execute(c.Request.Context(), dto); err != nil {
        switch {
        case errors.Is(err, library.ErrInvalidPath):
            c.JSON(http.StatusBadRequest, ErrorResponse{Error: "Invalid path"})
        case errors.Is(err, library.ErrDuplicatePath):
            c.JSON(http.StatusConflict, ErrorResponse{Error: "Path already exists"})
        default:
            c.JSON(http.StatusInternalServerError, ErrorResponse{Error: "Internal error"})
        }
        return
    }
    c.JSON(http.StatusCreated, response)
}
```

## Decision-Making Guidelines

### When to use Domain Service vs Application Use Case

**Domain Service** (`internal/domain/*/service.go`):
- Complex business logic
- Multiple entities interaction
- Domain-specific calculations
- Example: Media validation, filename parsing

**Application Use Case** (`internal/application/*/use_case.go`):
- Orchestrates domain services
- Handles transactions
- Converts DTOs ↔ entities
- Example: Create library, scan library, get media

### When to add a new layer

**DON'T** add layers unnecessarily:
- ❌ No service layer if use case is simple CRUD
- ❌ No DTO if entity can be returned directly
- ❌ No abstraction for single implementation

**DO** add layers when:
- ✅ Business logic is complex (domain service)
- ✅ External API needs different format (DTO)
- ✅ Multiple implementations expected (interface)

### ❌ DON'T: Import database driver in domain

```go
// internal/domain/media/entity.go
package media

import "database/sql" // ❌ WRONG!

type Media struct {
    ID sql.NullInt64 // ❌ WRONG!
}
```

### ✅ DO: Use plain Go types in domain

```go
// internal/domain/media/entity.go
package media

type Media struct {
    ID    int64  // ✅ Correct
    Title string // ✅ Correct

```

### ❌ DON'T: Write raw SQL in Go code

```go
rows, err := db.Query("SELECT * FROM media WHERE id = ?", id) // ❌ WRONG!
```

### ✅ DO: Use sqlc generated code

```sql
-- internal/infrastructure/database/sqlc/queries/media.sql
```

```go
media, err := queries.GetMediaByID(ctx, id) // ✅ Correct
```

```go
db.Where("id = ?", id).First(&media) // ❌ WRONG! (GORM example)
```

### ✅ DO: Use sqlc with proper queries

```go
media, err := r.queries.GetMediaByID(ctx, id) // ✅ Correct
```

```go
import (
    "testing"

        },
        {
            name: "invalid path",
            input: media.Media{Title: "Test", FilePath: "relative/path.mp4"},

        t.Run(tt.name, func(t *testing.T) {

            if (err != nil) != tt.wantErr {
                t.Errorf("want error: %v, got: %v", tt.wantErr, err)
            }
        })
    }
}
```

**Question**: Where do utility functions go?

#### 1. **Internal Utilities** (`internal/pkg/`)

Use for project-specific utilities that don't belong to any domain:

```
├── stringutil/         # String manipulation utilities
│   ├── slug.go         # Slugify, sanitize
```

**Rules**:

- ✅ Keep utilities small and focused (single responsibility)
- ❌ Don't put business logic here
- ❌ Don't create a "utils" catch-all package

**Example**:

```go
// internal/pkg/fileutil/hash.go
package fileutil

import (
    "crypto/sha256"
    "encoding/hex"
    "io"
    "os"
)

// HashFile returns SHA256 hash of a file
func HashFile(path string) (string, error) {
    f, err := os.Open(path)
    if err != nil {
        return "", err
    }
    defer f.Close()
    
    h := sha256.New()
    if _, err := io.Copy(h, f); err != nil {
        return "", err
    }
    
    return hex.EncodeToString(h.Sum(nil)), nil
}
```

### Anti-Patterns to Avoid

#### 1. **God Objects**

```go
❌ type MediaManager struct {
    // Too many responsibilities!
    scanner      *Scanner
    transcoder   *Transcoder
    metadata     *MetadataService
    notifier     *Notifier
    cache        *Cache
    db           *sql.DB
    ffmpeg       *FFmpeg
    // ... and more
}
```

**Solution**: Split into focused services

```go
✅ type MediaService struct {
    repo MediaRepository  // Single responsibility
}

✅ type ScanService struct {
    scanner Scanner
    repo    MediaRepository
}

✅ type TranscodeService struct {
    transcoder Transcoder
    queue      Queue
}
```

#### 2. **Anemic Domain Model**

```go
❌ type Media struct {
    ID    int64
    Title string
    Path  string
}

// All logic in services, entity is just data
```

**Solution**: Add behavior to entities

```go
✅ type Media struct {
    ID    int64
    Title string
    Path  string
}

func (m *Media) IsValid() error {
    if m.Title == "" {
        return ErrInvalidTitle
    }
    if !filepath.IsAbs(m.Path) {
        return ErrInvalidPath
    }
    return nil
}

func (m *Media) CanTranscode() bool {
    // Domain logic in entity
    return m.Codec != "h264" || m.BitRate > MaxDirectStreamBitRate
}
```

#### 3. **Package Cycles**

```go
❌ package library
import "viewra2/internal/domain/media"

❌ package media
import "viewra2/internal/domain/library"
```

**Solution**: Extract shared code or use interfaces

#### 4. **Deep Nesting**

```
❌ internal/infrastructure/database/repository/implementation/mysql/library/
```

**Solution**: Keep it flat

```
✅ internal/infrastructure/database/repository/library.go
```

## File Management & Naming Practices

### CRITICAL: No Version Suffixes or Temporary Names

**When refactoring or improving existing code:**

❌ **NEVER DO THIS:**
```
config.go          → config_old.go
                   → config_new.go

service.go         → service_v2.go
handler.go         → handler_enhanced.go
utils.go           → utils_improved.go
repository.go      → repository_refactored.go
media.go           → media_final.go
scanner.go         → scanner_backup.go
```

✅ **ALWAYS DO THIS:**
```
1. Make changes directly to the existing file
2. Git tracks the history - no need for backups
3. If splitting functionality, use descriptive names based on responsibility
```

### Refactoring Patterns

#### Pattern 1: Improving Existing Code
```
Task: "Improve error handling in media service"

❌ WRONG:
- Create internal/domain/media/service_enhanced.go
- Keep old service.go around

✅ CORRECT:
- Edit internal/domain/media/service.go directly
- Git will track changes
- User can revert if needed
```

#### Pattern 2: Splitting Large Files
```
Task: "Split media service - it's too large"

❌ WRONG:
internal/domain/media/
├── service.go           # Old file
├── service_new.go       # Split part 1
└── service_helper.go    # Split part 2

✅ CORRECT (by responsibility):
internal/domain/media/
├── service.go           # Core service (updated, smaller now)
├── scanner.go           # Scanning logic extracted
└── validator.go         # Validation logic extracted
```

#### Pattern 3: Replacing Implementation
```
Task: "Rewrite the scanner with better parsing"

❌ WRONG:
internal/domain/media/
├── scanner_old.go
├── scanner_v2.go
└── scanner_final.go

✅ CORRECT:
internal/domain/media/
└── scanner.go           # Just update the file
```

#### Pattern 4: Extracting to Utility
```
Task: "Extract file hashing to utility"

❌ WRONG:
internal/pkg/
├── utils.go
├── utils_new.go
└── helpers.go

✅ CORRECT:
internal/pkg/fileutil/
└── hash.go              # Descriptive name, focused purpose
```

### When Renaming Files

#### Decision Tree:

**Is the file's purpose changing?**
- **YES**: Rename to reflect new purpose
  ```
  media_scanner.go → filename_parser.go  # Purpose changed
  ```

- **NO**: Keep the same name, update content
  ```
  scanner.go → scanner.go  # Same purpose, better implementation
  ```

**Is the file too large and needs splitting?**
- **YES**: Split by responsibility with descriptive names
  ```
  service.go (1000 lines) →
    service.go (core logic)
    scanner.go (scanning)
    validator.go (validation)
  ```

- **NO**: Just improve the existing file
  ```
  service.go → service.go  # Same file, better code
  ```

### Naming Files After Refactoring

#### Base Name on WHAT, Not WHEN

❌ **Temporal/Version Names** (based on WHEN):
```
config_old.go
config_new.go
config_v2.go
config_enhanced.go
config_improved.go
config_refactored.go
config_final.go
config_final_v2.go
```

✅ **Descriptive Names** (based on WHAT):
```
config.go              # Main config struct
loader.go              # Config loading logic
validator.go           # Config validation
defaults.go            # Default values
```

**Domain Layer**:

## Security Patterns

### Path Validation & Traversal Prevention

**Always validate and sanitize paths**:

```go
// internal/pkg/validator/path.go
package validator

import (
    "errors"
    "fmt"
    "os"
    "path/filepath"
    "strings"
)

var (
    ErrInvalidPath     = errors.New("invalid path")
    ErrPathNotAbsolute = errors.New("path must be absolute")
    ErrPathTraversal   = errors.New("path contains invalid traversal")
    ErrPathNotReadable = errors.New("path is not readable")
)

func ValidateLibraryPath(path string) error {
    // Must be absolute
    if !filepath.IsAbs(path) {
        return fmt.Errorf("%w: %s", ErrPathNotAbsolute, path)
    }
    
    // Clean and check for traversal
    cleanPath := filepath.Clean(path)
    if strings.Contains(cleanPath, "..") {
        return fmt.Errorf("%w: %s", ErrPathTraversal, path)
    }
    
    // Must exist
    info, err := os.Stat(cleanPath)
    if err != nil {
        if os.IsNotExist(err) {
            return fmt.Errorf("path does not exist: %w", ErrInvalidPath)
        }
        return fmt.Errorf("cannot access path: %w", err)
    }
    
    // Must be directory
    if !info.IsDir() {
        return fmt.Errorf("path is not a directory: %w", ErrInvalidPath)
    }
    
    // Check readable
    if err := checkReadable(cleanPath); err != nil {
        return fmt.Errorf("%w: %s", ErrPathNotReadable, cleanPath)
    }
    
    return nil
}

func checkReadable(path string) error {
    // Try to open directory

        }
```

```go
// internal/infrastructure/cache/metadata.go
type MetadataCache struct {
    queries *db.Queries
}

func (c *MetadataCache) Get(ctx context.Context, key string) (string, error) {
    entry, err := c.queries.GetCacheEntry(ctx, key)
    if err != nil {
        return "", err
    }
    
    // Check if expired
    if entry.ExpiresAt.Valid && time.Now().After(entry.ExpiresAt.Time) {
        return "", ErrCacheExpired
    }
    
    return entry.Value, nil
}

func (c *MetadataCache) Set(ctx context.Context, key, value string, ttl time.Duration) error {
    expiresAt := sql.NullTime{}
    if ttl > 0 {
        expiresAt = sql.NullTime{
            Time:  time.Now().Add(ttl),
            Valid: true,
        }
    }
    
    return c.queries.UpsertCacheEntry(ctx, db.UpsertCacheEntryParams{
        Key:       key,
        Value:     value,
        ExpiresAt: expiresAt,
    })
}
```
